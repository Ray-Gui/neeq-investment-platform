核心论点

医疗健康的独立配置价值不在"买下 386 家新三板样本"，而在 精选转板期权 + 北交所头部质量。中性方以实查数据确立了本报告的方法论基石：有流动性的标的（已转板头部）期权已行权完毕，有期权的标的（未转板主体）几乎没有流动性。因此唯一可执行的形态是 L1/L2/L3 三层结构，而非单一仓位。

关键数字

  • 景气与环境背离：中证医疗 6465.83（YTD −4.35%，MA5>MA10>MA20>MA30>MA60 多头）vs 北证50 1076.17（YTD −25.29%，全周期空头）；YTD 相对强度差 +20.94pp，比价 4.842→6.008（+24.1%），Beta ≈ 0.28。
  • 头部盈利质量与总量平庸并存：头部标的 2025-FY 毛利率 89.21% / 84.08% / 70.02%（锦波生物 / 德源药业 / 星昊医药，NeoData 实拉自算），而新三板 28 家样本平均毛利率仅 16.37%、A 股 56 家 18.63%；规模差 6 倍以上（2.92 亿 vs 18.5 亿）。
  • 估值不在高位：北交所三家盈利头部 PE 中位数 17.6x（自算：总市值 / 2025-FY 归母净利），较中证医疗 29.81 折价 40.8%、较北证50 42.94 折价 58.9%。
  • 期权赔率明牌、概率不明牌：转板重估区间 2–4 倍；盈亏平衡概率门槛（底稿口径）9.1% / 16.7% / 33.3%；随机撒网概率 3–6%（负期望），精选后 20–40%（正期望）。

主要风险

  • 流动性陷阱：386 家未转板主体日成交 0–50 万，无法执行止损，L3 必须按本金归零配置。
  • 系统性 Beta：北证50 趋势性下跌（ADX 59），清仓线 984.10 距现价仅 −8.56%；压力测试情景 747 对应 −30.59%（概率 15–20%）。
  • 支付端逆风：医保支付端 6 月 −13.3% 且三连降，压制仿制药 / 传统 IVD / 低端耗材；公募医药持仓 6.73% 十年新低（该子维度评分仅 4.0）。

关键催化

  • 北证50 放量站回 MA20 1106.89 满三日（距现价 +2.85%）→ L2/L3 提速；
  • 首个医疗标的转板过会案例 → L3 期权定价重估、第三批触发；
  • 公募医药持仓回升至 7.5%+ → 左侧论证成立的反向确认。

投资要点（Key Takeaways）

  1. 行业具备独立配置价值，但必须分层。医疗健康的价值在于"精选转板期权 + 北交所/科创板头部质量"，而非把 386 家新三板当作一个仓位整体下注。
  2. 核心洞察：流动性与转板期权负相关。有流动性的（北交所头部）期权已行权完毕，有期权的（386 家未转板）几乎无流动性。激进方与保守方各自想象的"理想标的"都不存在，必须 L1/L2/L3 分层。
  3. 政策强正面、支付端逆风并存。北交所改革、转板常态化、创新药 License-out 持续放量构成制度红利；但医保支付端连续下滑（6 月 −13.3%，三连降）压制仿制药/IVD/低端耗材。
  4. 当前是左侧窗口，非右侧趋势。中证医疗技术面短中期多头，北证50 仍趋势性下跌（YTD −25.29%）；两者 20 日窗口相关性为负，止损必须"双条件"，单边触发不动作。
  5. 执行方案：L1 现在买、L2 等确认、L3 按归零配置。L1 中证医疗 ETF 5–6%（完全可逆）；L2 北交所头部 2–3%（等 MA20 确认）；L3 新三板精选 1–1.5%（纯期权、不可逆、按本金归零假设）。
  6. 【加厚版新增】头部质量已被财报证实，且估值未被透支。四家代表标的 2025-FY 实拉：营收 15.95 / 10.58 / 6.50 / 0.66 亿元，ROE 34.44% / 18.13% / 6.23% / −16.45%，盈利头部 PE 13.0–22.8x，显著低于北证50 整体 42.94。质量与估值同时成立，是 L2 层的核心支撑。
  7. 【加厚版新增】敞口 8–10% 决定了组合层面的量级有限。三情景测算显示组合贡献区间仅 −1.36pp ~ +1.52pp（中性 +0.13pp）。这既是风控优点（可承受），也提示不应对本主题抱有组合级别的收益期待——它是期权配置，不是收益引擎。

5.5　估值三法：可比法 / 反向 DCF / PS · 重置成本

（一）可比 PE / PB 法 —— 可执行

三家盈利标的静态 PE 为 13.0x / 17.6x / 22.8x，中位数 17.6x。以此对照两个指数估值：较中证医疗 PE(TTM) 29.81 折价 40.8%，较北证50 PE(TTM) 42.94 折价 58.9%。

这一折价的解释必须谨慎，它同时可以支持多空两方 多头读法：北交所医疗盈利头部以 17.6x 中位 PE 提供了 34.44% / 18.13% 的 ROE，质量—价格比优于两个指数整体，L2 层"头部质量"论点成立。 空头读法：折价本身正是流动性折价的市场定价结果——底稿实测北交所整体成交萎缩至 181 亿（vs 年初 260 亿），折价 40–59% 恰恰是市场对退出成本的合理索取，不等于低估。 本报告裁定：两种读法都成立，因此折价不能单独作为买入理由，只能作为"L2 头部在给定风险下未被高估"的约束条件——这与风险主管"L2 流动性权重降至 5–6、L3 维持 9"的分层裁定完全一致。

（二）简版 DCF —— 以反向 DCF（隐含增长率）替代，仅 1 家数据支持

术语表 / 样本口径 / 置信度提示

附录 A　术语表

L1 / L2 / L3 分层
本报告的配置结构。L1 = 流动性层（中证医疗 ETF / A 股医药龙头，完全可逆）；L2 = 半流动层（北交所已上市医疗头部）；L3 = 期权层（新三板未转板精选，不可逆、按归零配置）。
转板期权
新三板企业晋级北交所所带来的估值重估机会。底稿测算历史重估区间 2–4 倍（流动性溢价 + 估值体系切换）。其本质是期权而非承诺——赔率明牌、概率不明牌。
盈亏平衡概率 p*
使期望值为零的最低成功概率，p* = L/(G+L)，G 为成功时收益、L 为失败时损失。底稿口径 9.1%/16.7%/33.3%（隐含残值 > 0）；本报告并列给出归零口径 25%/33.3%/50%（L = 100%）。
基准代理（Benchmark Proxy）
因研究对象无可用连续行情而借用其他指数刻画其环境与景气的方法。本报告用北证50 代理交易场所环境、中证医疗代理行业景气。
双条件止损
因两代理 20 日窗口相关性为负，单一代理触发不足以证明风险实现，故要求北证50 与中证医疗同时破位方才减仓。
License-out
创新药企将在研管线的海外权益授权给跨国药企，换取首付款 + 里程碑 + 销售分成。其金额同比走势是本报告"创新药出海"逻辑的核心跟踪指标。
Biosecure
境外针对生物医药供应链的立法动向，是 CXO 赛道被列为"最小且延后"的主要外部风险来源。
ADX / VR / AR·BR / ATR
ADX = 趋势强度指标（不辨方向，越高趋势越强）；VR = 成交量比率（>100 偏放量）；AR/BR = 人气/意愿指标；ATR = 真实波幅均值，用于刻画波动幅度。
ROE（期末净资产口径）
本报告个股 ROE = 归母净利润 ÷ 期末净资产（资产合计 − 负债合计）。与年报披露的"加权平均净资产收益率"口径不同，后者以期间加权净资产为分母，两者数值会有差异。
反向 DCF
不预测未来现金流，而是反推"当前市值隐含了多高的永续增长率"，用于检验价格中已包含的乐观程度。公式 g = WACC − FCF/EV。
pp（百分点）
percentage point。第 8 章"组合贡献 +1.52pp"指该主题使整个组合收益率提高 1.52 个百分点，而非该主题自身上涨 1.52%。
扣非
扣除非经常性损益后的净利润，用于剔除一次性收益对盈利质量的干扰。
